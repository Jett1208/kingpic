# ADR 0003: Star Rating Criteria and Infinite Seeded Stages

## Status
Accepted

## Context
จำเป็นต้องระบุเกณฑ์การให้คะแนนดาวในหน้าสรุปจบด่าน (StageSummaryModal) และโครงสร้างการจัดเก็บด่านว่ามีจำนวนสิ้นสุดเท่าใด เพื่อรองรับการเล่นระยะยาว

## Decision
1. **เกณฑ์ดาว 3 ดวง (Star Rating Rules):**
   - ⭐️ **ดาวที่ 1 (Victory):** ตีป้อมบอสแตกผ่านด่านสำเร็จ (ได้แน่นอนเมื่อจบด่าน)
   - ⭐️ **ดาวที่ 2 (Total Domination):** ทำลายสิ่งก่อสร้างและศัตรูครบ 100% ทั้งแผนที่
   - ⭐️ **ดาวที่ 3 (Speed Runner):** เคลียร์ด่านภายในเวลาเป้าหมาย ($\text{Clear Time} \le \text{Par Time}$)
2. **ระบบด่านไม่สิ้นสุด (Infinite Stages):**
   - ใช้ Seeded Random `mulberry32(stageNumber * 9973)` ทำให้สามารถสร้างด่านที่ $1, 2, 3, \dots, N$ ได้ไม่รู้จบ
   - เมื่อผ่านด่านที่ $S$ ด่านที่ $S+1$ จะถูกปลดล็อกทันที และบันทึก Highest Unlocked Stage และจำนวนดาวที่ได้ลงใน `localStorage` ผ่าน Zustand
   - หน้าจอเลือกด่าน (Stage Select) จะแสดงกริดด่านที่ปลดล็อกแล้วพร้อมจำนวนดาวที่ทำได้

## Consequences
- เกมมีความสามารถในการเล่นซ้ำ (Replayability) สูงมาก แม้ด่านจะมีขั้นตอนการสร้างอัตโนมัติ แต่การจัดวางจะตายตัวเสมอสำหรับแต่ละเลขด่านเดิม
- ผู้เล่นสามารถย้อนกลับมาเก็บ 3 ดาวในด่านเก่าได้ตลอดเวลา
