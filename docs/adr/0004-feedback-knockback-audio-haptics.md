# ADR 0004: Soft Knockback, Chiptune Audio Engine, and Haptic Feedback

## Status
Accepted

## Context
เนื่องจากราชาและทหารไม่มีวันตาย (Invincible) เพื่อไม่ให้เกมรู้สึกขาดความท้าทายหรือกลายเป็นแค่การเดินชนหุ่นนิ่งๆ และเพื่อให้ผู้สูงอายุได้รับความพึงพอใจทางประสาทสัมผัส (Tactile & Sensory Satisfaction)

## Decision
1. **การตอบโต้ของศัตรู (Soft Knockback & Interruption):**
   - ป้อมธนูจะยิงลูกศร และมอนสเตอร์สีแดงจะพุ่งเข้าใส่ราชา
   - เมื่อถูกโจมตี ราชาจะไม่เสียเลือด แต่จะเกิดอาการสะดุด (Knockback เล็กน้อย + ชะลอความเร็ว 0.2 วินาที) พร้อมเสียง 'Ouch/Clang' 8-bit และประกายไฟ
   - ช่วยให้ผู้เล่นรู้สึกว่าป้อมและมอนสเตอร์มีอันตรายและคุ้มค่าที่จะกำจัด
2. **ระบบเสียงสังเคราะห์เต็มรูปแบบ (Web Audio API Synthesizer):**
   - มีทั้ง Sound Effects (ฟันดาบ, เหรียญเด้ง, กรงแตก, ราชาสะดุด, ไชโยชนะ)
   - มีเพลงพื้นหลัง 8-bit Chiptune วนลูป สังเคราะห์ขึ้นสดๆ (ไม่ต้องโหลดไฟล์ mp3 ขนาดใหญ่ ทำให้โหลดไวและเล่นออฟไลน์ได้ 100%)
   - มีปุ่มสลับเสียง เปิด-ปิด (Mute Toggle) ขนาดใหญ่ชัดเจนบนแถบ HUD
3. **การสั่นสะเทือน (Haptic Vibration):**
   - รองรับ `navigator.vibrate` บนมือถือ
   - สั่นสั้นๆ 20ms เมื่อเก็บเหรียญ/ตีรั้ว
   - สั่นหนัก 60ms-100ms เมื่อพังกรงทหารหรือระเบิดป้อมบอส
   - ระบบจะตรวจจับอัตโนมัติ หากอุปกรณ์ไม่รองรับก็จะไม่เกิด Error

## Consequences
- ผู้สูงอายุจะได้รับประสบการณ์เกมที่ตื่นเต้น มีชีวิตชีวา และจับต้องได้ชัดเจน
- โปรเจกต์ไม่ต้องพึ่งพา External Asset ไฟล์เสียงขนาดใหญ่ ทำให้ PWA มีขนาดเบามาก (ไม่กี่ร้อย KB)
