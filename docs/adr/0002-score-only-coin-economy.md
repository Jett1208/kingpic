# ADR 0002: Score-Only Coin Economy and Pure Arcade Progression

## Status
Accepted

## Context
มีการพิจารณาว่าเหรียญที่เก็บได้ควรนำไปซื้ออัปเกรดถาวร (Metagame Shop / Stat Upgrades) หรือคงไว้เป็นคะแนนสะสมและเสาเหรียญเชิงความรู้สึก (Visual Score & Trophy)

## Decision
- เหรียญในเกมทำหน้าที่เป็น **คะแนนสะสม (Score & Trophies)** และเสาเหรียญจำลองความมั่งคั่งบนศีรษะราชา
- ไม่เพิ่มระบบร้านค้าอัปเกรดที่ซับซ้อน เพื่อรักษาความเรียบง่าย เข้าใจได้ทันทีโดยไม่ต้องเรียนรู้ระบบ Menu/Inventory/Tree สำหรับผู้สูงอายุ
- การเติบโตกองทัพเกิดขึ้นภายในด่านโดยตรง (In-run Expansion) ผ่านการพัง "กรงขังเพื่อน" เพื่อเพิ่มจำนวนทหารและขยายวงรัศมีออร่า

## Consequences
- ลดภาระความจำและการตัดสินใจของผู้เล่นรุ่นใหญ่
- ลดความซับซ้อนของ State Management และ Database
- อากงสามารถกดเลือกด่านและเริ่มเล่นได้ทันทีเพียงปุ่มเดียว
