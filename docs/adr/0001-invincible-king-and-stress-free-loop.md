# ADR 0001: Invincible King and Stress-Free Core Loop

## Status
Accepted

## Context
เป้าหมายของโปรเจกต์คือเกมบนเว็บสำหรับผู้สูงอายุ ("เกมของอากง") ซึ่งได้รับแรงบันดาลใจจากโฆษณาเกม Kingshot ที่เน้นความพึงพอใจในการนำกองทัพไปกวาดล้างสิ่งก่อสร้างและสะสมเหรียญ
ในการออกแบบระบบเกม มีข้อถกเถียงว่าราชาควรมีหลอดเลือดและสามารถถูกศัตรู/ป้อมธนูโจมตีจนแพ้ได้หรือไม่ รวมถึงควรมีระบบเวลาจำกัดที่บังคับแพ้หรือไม่

## Decision
1. **ราชาไม่มีหลอดเลือด (Invincible):** ราชาและกองทัพทหารไม่สามารถตายได้ ไม่มีการปรับสถานะ Game Over จากการโดนโจมตี
2. **เงื่อนไขชนะชัดเจน:** การทำลาย "ป้อมบอส (Boss Tower)" ด้านบนสุดของด่านถือเป็นเงื่อนไขชนะและจบด่านทันที
3. **ระบบเวลาไม่กดดัน:** เวลาเป้าหมาย (Par Time) ใช้สำหรับคิดคะแนนดาว (3 ดาว) เท่านั้น หากเวลาเกิน ผู้เล่นยังคงเล่นต่อได้จนกว่าจะตีบอสแตกโดยไม่ปรับแพ้
4. **เปอร์เซ็นต์ % คือเควสต์เสริม:** เปอร์เซ็นต์การทำลายล้าง 0-100% บน HUD บ่งบอกการกวาดล้างสิ่งก่อสร้างทั้งหมดในด่านเพื่อรับดาวเต็ม

## Consequences
- **ข้อดี:** อากงเล่นได้อย่างเพลิดเพลิน ไม่เกิดความเครียดหรือความหงุดหงิดจากการแพ้ซ้ำซาก
- **ข้อดี:** การควบคุมบนหน้าจอสัมผัสไม่จำเป็นต้องหลบหลีกกระสุนอย่างรวดเร็ว (Low reflex requirement)
- **ข้อจำกัด:** เกมจะไม่มีความท้าทายแบบ Survival แต่จะเน้นความเพลิดเพลินแบบ Arcade Power Fantasy แทน
